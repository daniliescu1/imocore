# Imo Core

Aplicație pentru administrarea imobilelor, spațiilor, contractelor, rezervărilor, utilităților, anexelor și facturării.

Proiect separat de **OperApp** (operațional / taskuri).

## Stack (planificat)

- Laravel
- Laravel Forge (deploy)
- DigitalOcean (server)
